# System Code

This directory is the submission index for the implemented system. The canonical source stays in its existing root-level locations so CI, deployment tooling, and developer commands continue to resolve their established paths.

## Components

- [`backend/`](../backend/README.md) contains the Django/ASGI services, agent and navigation integrations, inference interfaces, deployment tooling, and backend checks.
- [`frontend/`](../frontend/README.md) contains the browser application, navigation and speech clients, camera streaming, integration pages, and frontend checks.

Run commands and runtime boundaries are documented in the component guides. This index does not duplicate or copy application files.
